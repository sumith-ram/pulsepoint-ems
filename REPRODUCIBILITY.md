# Reproduction boundary

This exact export is documentation and selected visual/aggregate evidence. It contains no runnable application source, package manifest, model, raw input or environment. Reading the Markdown/JSON and checking the file manifest is reproducible from this tree; application behavior and historical numerical results cannot be fully reproduced from it.

The canonical project separately documents installation, testing and evidence regeneration. Those commands depend on source, dependencies and omitted data/model/configuration. Do not paste them here as if this export were runnable. No credential, private path or unreleased repository URL is required to review this package.

Current checks and historical checks are separated in [validation](VALIDATION.md). [Source-release decision](SOURCE_RELEASE_DECISION.md) explains what would be needed for a subsequent runnable source distribution.
